Boundary = represents the endpoint/routes 
Control = represents the usecase biz logic (coordinates everything)
Entity = represents the class stored in the database
Schemas = defines what the client is allowed to send

Database: postgresql://postgres:password@localhost:5432/SIM2026Q4Mag5

FastAPI Architecture:
backend/
├── main.py
├── boundary/
├── control/
├── entity/
├── schemas/
├── database/
└── utils/



Register module 

POST /register
        │
        ▼
register_boundary.py
        │
        ▼
register_control.py
        │
        ├── check existing user
        ├── hash password
        └── create User
                │
                ▼
            database


Login Module

                 POST /login
                     │
                     ▼
              login_boundary.py
                     │
                     │ Receive and validate login request
                     ▼
               login_control.py
                     │
                     ├── Find user by email
                     │
                     ├── Check if user exists
                     │
                     ├── Verify password against stored hash
                     │
                     ├── Generate JWT access token
                     │
                     └── Retrieve user's role
                              │
                              ▼
                           Database
                       (Read user record)
                              │
                              ▼
                       Return to Boundary
                              │
                              ├── Set JWT in HTTP-only cookie
                              │
                              └── Return login response
                                      │
                                      ▼
                                  Frontend
                              (Redirect based on role)
