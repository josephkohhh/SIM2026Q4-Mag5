Boundary = represents the endpoint/routes 
Control = represents the usecase biz logic (coordinates everything)
Entity = represents the class stored in the database
Schemas = defines what the client is allowed to send

Database: postgresql://postgres:password@localhost:5432/SIM2026Q4Mag5

FastAPI Architecture:
backend/
├── main.py
├── boundary/
├── control/
├── entity/
├── schemas/
├── database/
└── utils/



Register module 

POST /register
        │
        ▼
register_boundary.py
        │
        ▼
register_control.py
        │
        ├── check existing user
        ├── hash password
        └── create User
                │
                ▼
            database


Login module

POST /login
    │
    ▼
login_boundary.py
    │
    ▼
login_control.py
    │
    ├── find user by email
    │
    ├── check if user exists
    │
    ├── verify password hash
    │
    ├── establish session and return user role 
    │
    └── return login response
            │
            ▼
         database
      (read user record)
